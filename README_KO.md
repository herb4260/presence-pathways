# Presence Pathways 한국어 안내

이 프로젝트는 다음 질문을 실제 연구 설계로 바꾼 것입니다.

> 신적 은혜로 이해된 경험은 어떻게 치유의 과정이 되며, 그 변화는 주의·감정·관계·서사·공동체라는 경로를 통해 어떻게 지속되는가?

## 왜 이 프로젝트가 중요한가

단순히 “기도를 많이 하면 우울 점수가 낮아지는가?”만 묻지 않습니다. 가슴이 따뜻해짐, 눈물, 평안, 사랑받는 느낌, 감사, 걱정의 완화처럼 체험이 몸과 마음에서 어떻게 나타나는지 매일 기록합니다. 이후 심층 인터뷰를 통해 참여자가 그 변화를 어떤 언어와 관계 속에서 이해하는지 살핍니다.

## 구성

- 21일 경험표집(EMA) 합성 데이터
- 영어·한국어 EMA 문항
- 현상학적 심층 인터뷰 가이드
- 개인 내 변화 분석
- 다음 날까지 이어지는 변화 분석
- 연구자가 반드시 검토해야 하는 인터뷰 코드 제안
- GitHub Pages에서 실행되는 연구 대시보드
- 연구윤리·성찰성·분석계획 문서

## 중요한 원칙

이 코드는 하나님의 존재를 증명하거나 부정하지 않습니다. 또한 영적 체험을 자동으로 정신질환으로 분류하지 않습니다. 숫자는 인터뷰와 민족지적 해석을 보조할 뿐, 체험의 의미를 대신하지 않습니다.

실제 참여자 자료는 공개 저장소에 올리면 안 됩니다. 현재 포함된 모든 데이터와 인터뷰 문장은 프로그램이 만든 합성 자료입니다.

## 실행

```bash
pip install -e .
python scripts/build_demo.py
python -m unittest discover -s tests -v
python -m http.server 8000 --directory docs
```

브라우저에서 `http://localhost:8000`을 열면 됩니다.

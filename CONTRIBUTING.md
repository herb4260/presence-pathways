# Contributing

Contributions are welcome when they preserve the project's interpretive and ethical commitments.

1. Open an issue describing the research or software problem.
2. Create a focused branch and add tests for behavioral changes.
3. Run `python scripts/build_demo.py` and `python -m unittest discover -s tests -v`.
4. Do not commit real participant data, identifiable testimony, credentials, or private fieldnotes.
5. Describe how the contribution affects interpretation, privacy, and reproducibility.

Automated text processing must remain a suggestion layer. Human researchers retain responsibility for qualitative coding and interpretation.
